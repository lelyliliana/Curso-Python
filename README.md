# 🧭 ¿Cómo utilizar este repositorio?

Si estás comenzando en Python, lo recomendable es seguir las unidades **en orden**.

Cada unidad incluirá:

1. Una explicación de los conceptos.
2. Ejemplos desarrollados paso a paso.
3. Instrucciones para ejecutar los programas.
4. Explicación del código.
5. Errores frecuentes.
6. Ejercicios para practicar.
7. Un reto de aplicación.

No te limites a leer el código.

**Ejecuta los ejemplos, modifícalos y observa qué ocurre.**

La programación se aprende programando.

# 🧩 Metodología

A lo largo del repositorio encontrarás ejemplos pequeños que permiten comprender cada concepto de manera independiente.

También encontrarás ejercicios que evolucionarán progresivamente.

Por ejemplo, un programa sencillo podrá comenzar utilizando variables y posteriormente incorporar:

```text
Variables
   ↓
Condicionales
   ↓
Ciclos
   ↓
Colecciones
   ↓
Funciones
   ↓
Programación orientada a objetos
   ↓
Archivos y bases de datos
   ↓
APIs
   ↓
Pruebas
```

De esta manera podrás observar cómo los conceptos aprendidos se combinan para construir aplicaciones cada vez más completas.
